# RUBOR — Casa de maquillaje (tema-estudiante)

Proyecto integrador de WordPress Avanzado, hecho por Sofía. Es una tienda de maquillaje en WordPress con un tema propio llamado `tema-estudiante`.

**Abrir la tienda en el navegador (no hay que instalar nada):**
https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/AGL-J/rubor-wordpress/main/blueprint.json

El enlace arma el sitio solo en 2 o 3 minutos. Al terminar, el sitio tiene:

- WordPress en español de Colombia.
- El tema `tema-estudiante`.
- 8 plugins: WooCommerce, Contact Form 7, Flamingo, Yoast SEO, Joinchat, Cache Enabler, Modern Image Formats y Query Monitor.
- Bastionado activado (`DISALLOW_FILE_EDIT`).
- El rol personalizado **Redactor Jr.**
- 16 productos, 6 entradas y las páginas de la tienda.

Los pagos son de demostración: no se cobra dinero real.
